# 7분임 슈퍼비전 시트 — 최종본

박윤아 · 강희강 · 임충만 · 김규리 선생님의 표적행동 기록 시트를 **같은 규칙**으로 다시 만든 최종본입니다.

| 폴더 | 내용 | 누구에게 |
|---|---|---|
| `final/` | 배포용 최종본 4개 (기록지·요약·양식 전체, 예시 자료 없음) | 슈퍼바이지(선생님) |
| `internal/` | 설명용(내부) 4개 = 최종본 + 예시(가상) 자료 + 첫 탭 `설명 스크립트(슈퍼바이저용)` | 슈퍼바이저만 |
| `source/` | 이번 작업의 출발점이 된 원본 시트 내려받기본(재생성용) | — |
| `tools/` | 위 8개 파일을 만드는 스크립트 (`python3 tools/make_all.py`) | — |

## 구글 시트로 올리는 법
1. 구글 드라이브에 `final/`의 파일을 끌어다 놓습니다.
2. 파일을 열어 **파일 → Google Sheets로 저장**을 누릅니다(드롭다운·색·수식·그래프가 그대로 옵니다).
3. 인쇄는 해당 탭에서 **Ctrl+P → A4 가로 → 배율 '너비 맞춤'**. (파일 ID에 묶인 PDF 링크는 뺐습니다.)

## 색 규칙 (4개 파일 공통)
- **노란 칸** = 4회기 전까지 채우거나 확인할 칸
- **파란 글씨** = 꼭 지킬 지침
- **회색 칸** = 자동 계산, 입력하지 않기 / 회색 기울임 글씨 = 예시 / 회색 글씨(양식5·6) = 슈퍼바이저 초안
- 빨간 글씨·하늘색 칸은 쓰지 않습니다.

## 기록 방식 한눈에
| 선생님 | 기록지 | 한 줄 | 칸에 적는 것 | 분포도 |
|---|---|---|---|---|
| 박윤아 | `인쇄_기록지` → `2.기록지` | 한 회차(지시 10개) | 지시마다 ○ △ 이 · 턱 때리기 횟수 | 불필요(선생님 혼자) |
| 강희강 | `인쇄_기록지` → `2.기록지` | 한 회차(문항 10개) | 문항마다 ○ 요 T | 불필요(선생님 혼자) |
| 임충만 | `양식4_분포도` → `2.기록지` | 하루 | 교시별 횟수 · 상처 ★ · 말로 요청 횟수 | 필요(모든 선생님 매 교시) |
| 김규리 | `양식4_분포도` → `2.기록지` | 한 교시 | ○ △ × 개수 · 끝까지 참여 Y/N · 위기행동 | 필요(통합학급 교과 선생님 포함) |

## 탭 구성 (공통)
`0.진행 지도` → `1.정의` → `2.기록지` → 인쇄/분포도 → `3.요약` → `4.중재 설계(초안)` → 양식1·2·3·5·6·7 (김규리: `5.학생 점검 카드` 추가)

## 재생성
```
pip install openpyxl
python3 tools/make_all.py          # final/ 과 internal/ 을 다시 만듭니다
```
문구·설정은 `tools/cfg_*.py`, 공통 규칙은 `tools/lib.py` · `sheets.py` · `records.py` · `summary.py` · `forms.py`에 있습니다.
